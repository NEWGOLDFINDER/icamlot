=========================================================
  AJOUTER UN BILAN / ARTICLE  —  c'est très simple
=========================================================

1) Crée un nouveau dossier ici, dans "bilans/".
   Donne-lui un nom court sans espaces ni accents, par exemple :
   bilans/coupe-de-belgique-2027/

2) Dans ce dossier, mets deux choses :

   • cover.jpg      -> la photo affichée sur la carte du carrousel
   • article.md     -> le texte de l'article (voir modèle ci-dessous)

   (Tu peux aussi y mettre d'autres photos et les afficher dans
    l'article, voir plus bas.)

3) Envoie sur GitHub (commit + push). C'est tout !
   L'article apparaît automatiquement, trié par date, et se place
   au bon endroit dans le carrousel des bilans.

---------------------------------------------------------
  MODÈLE de fichier "article.md"
---------------------------------------------------------
---
titre: Coupe de Belgique 2027
date: 2027-04-18
resume: Une phrase de résumé affichée sur la carte du carrousel.
---
Ici tu écris le texte complet de l'article.

Tu peux sauter des lignes pour faire des paragraphes, mettre du
**gras**, de l'*italique*, des listes :

- premier point
- deuxième point

Pour afficher une photo (mets-la dans le même dossier que ce fichier) :

![](photo-du-match.jpg)

Pour intégrer une VIDÉO, deux possibilités :

  a) VIDÉO YOUTUBE : colle le lien sur une ligne seule (rien d'autre) :
       https://www.youtube.com/watch?v=xxxxxxxxxxx

  b) VIDÉO MP4 (sans lecteur YouTube) : mets le fichier .mp4 dans le
     dossier de l'article, puis écris-le comme une image :
       ![](ma-video.mp4)
     (formats acceptés : .mp4 .webm .ogg .mov)
     -> un lecteur vidéo simple s'affiche, hébergé sur votre site.

  Conseil : garde les .mp4 courts et légers (idéalement < 20-30 Mo),
  sinon préfère YouTube pour les longues vidéos.
---------------------------------------------------------

Notes :
- "date" au format AAAA-MM-JJ (année-mois-jour).
- Si tu ne mets pas de cover.jpg, la bannière du site est utilisée.
- Le fichier "liste.json" sert uniquement de secours ; normalement
  les dossiers sont détectés tout seuls. Si tu veux, tu peux y ajouter
  le nom de ton dossier, mais ce n'est pas obligatoire.
